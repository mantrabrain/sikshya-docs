## Free vs Pro at a glance

| Capability                                                   | Free | Pro |
| ---                                                          | ---  | --- |
| Unlimited courses, lessons, quizzes, students                | ✅   | ✅  |
| Course builder + drag-and-drop curriculum                    | ✅   | ✅  |
| Quizzes (multiple choice, true/false, short answer)          | ✅   | ✅  |
| Assignments (basic) + certificates (basic)                   | ✅   | ✅  |
| Sequential lesson progression                                | ✅   | ✅  |
| Native checkout, free + paid courses, manual enrollment      | ✅   | ✅  |
| **PayPal** + **Stripe\*** gateways                           | ✅   | ✅  |
| Coupons (% / fixed, redemption limits, date window)          | ✅   | ✅  |
| Student dashboard + wishlist                                 | ✅   | ✅  |
| Transactional emails (enrollment, purchase, completion)      | ✅   | ✅  |
| Razorpay · Mollie · Paystack · Square · Authorize.Net · Bank Transfer | — | ✅ |
| **Content drip** (date / X-days / cohort)                    | —    | ✅  |
| **Prerequisites** (lessons + courses)                        | —    | ✅  |
| **Course bundles** &amp; **subscriptions**                    | —    | ✅  |
| **Multi-instructor** + revenue split                          | —    | ✅  |
| **Gradebook** + advanced assignments + advanced quizzes       | —    | ✅  |
| **Advanced certificates** (builder + QR + verification)       | —    | ✅  |
| **Course reviews** &amp; **Q&amp;A / discussions**            | —    | ✅  |
| **Calendar** &amp; **live classes** (Zoom / Meet)             | —    | ✅  |
| **Activity log** &amp; **enterprise reports**                 | —    | ✅  |
| **Webhooks**, **Zapier**, **public API keys**                 | —    | ✅  |
| **Marketplace** (multi-vendor) + commissions                  | —    | ✅  |
| **White label**, **multisite**, **multilingual**, **SCORM/H5P** | —  | ✅  |

> Pro add-ons are toggled per-site under **Sikshya → Add-ons**. License plans (Starter / Pro / Scale) gate which add-ons can be enabled. Buy or compare plans on [mantrabrain.com](https://mantrabrain.com/plugins/sikshya/#pricing).

- 👥 Join the [Sikshya LMS Facebook Community](https://www.facebook.com/groups/sikshyalms/) for peer discussion.
- 💎 Pro license holders get [priority support](https://mantrabrain.com/plugins/sikshya/#pricing) — see [Support](/guide/support) for routing details.
